## Reproduce independent validation

Go 1.27.3 is required by upstream Tailscale 1.104.2.

```sh
GOWORK=off go mod verify
GOWORK=off go list -m -json github.com/quic-go/quic-go github.com/refraction-networking/utls
GOWORK=off go test -mod=readonly -race ./wgengine/... ./net/dns ./tstest/integration/testcontrol -count=1
GOWORK=off go build -mod=readonly ./cmd/tailscale ./cmd/tailscaled
```

These checks passed, as did native Darwin and CGO-disabled Linux/Windows amd64
builds. Linux/Windows were cross-compiled, not exercised as live endpoints.
The QUIC fork passed `GOWORK=off go test -mod=readonly -race -short ./... -count=1`;
uTLS passed its complete root-package short race suite. Short suites exclude
some long-running stress tests. Module selection points into the Go module
cache, not the sibling source directories.

## Review scope

The QUIC fork's `DEPENDENCIES_20261021.md` records merge decisions. Inspect its
unified packet-number/history integration, BBR discard/application-limited/flight
hooks, explicit-rate pacing and conservative single-spurious-packet behavior.
BBRv3 remains the production default, including migration. The Initial-packet
`EMSGSIZE` fallback now reduces the BBR byte window with packet size instead of
panicking. A regression reproduced the panic before the fix.

Also review the earlier authenticated ticket journal, single-use replay
protection, revocation/reconnect behavior and uTLS session events. DATAGRAM
borrowing remains synchronous; asynchronous queues retain owned data and bounds.

## Mixed-load acceptance remains separate

One independent-build regression transferred exactly one GiB in each direction,
with matching SHA-256. Local samples were 910.84/936.07 Mbps. Simultaneous UDP
delivered 9301/9302 packets, with no duplicates or reordering. This is one local
regression trial, not paired throughput/UDP nonregression evidence or a WAN gain.

Burst-loss, reordering and asymmetric-link tests completed all 18 functional
windows, but the UDP repair-on/off gate failed 10/18 directional comparisons:
nine involve non-finite unconditional P99, two exceed the loss delta and one
regresses finite P99 (reasons overlap). Asymmetric trial 0 direction 0 changed
P99 from 38.757 to 55.906 ms. Missing packets remain in the quantile population;
the gate was not relaxed and completed workloads were not rerun for better data.

Keep TCP repair off by default. No FEC was added. Fixing module resolution does
not qualify earlier performance experiments for release. Candidate allocation
and queue changes are active when this review branch uses the new dependency;
they do not share a global runtime switch with `TCPRepair`.
